# Помощник стажёра

Отдельное приложение FastAPI. Для локального запуска из корня репозитория:

```sh
.venv/bin/python -m uvicorn intern_assistant.main:app --host 127.0.0.1 --port 8012
```

Открыть http://127.0.0.1:8012/. Готовые вопросы ведут к типовым ситуациям, свободный текст сопоставляется с темами из `web/data/intern-assistant.json`. Чат учитывает разговорные выражения, ограниченные опечатки и русские вопросы, набранные в латинской раскладке. При нехватке сведений чат направляет к HR или наставнику. Для рабочих ситуаций можно запросить и скопировать черновик сообщения.

## Встраивание

Подключить приложение по отдельному пути **до** корневой раздачи статики в приложении сайта:

```python
from intern_assistant.main import app as intern_assistant

app.mount("/assistant", intern_assistant)
```

Страница на `/assistant/`. При необходимости её можно встроить через `<iframe src="/assistant/" title="Помощник стажёра"></iframe>`. Интерфейс также можно заменить, сохранив API. `GET /assistant/api/topics` возвращает готовые вопросы. `POST /assistant/api/ask` принимает `{"question":"Как рассказать о перегрузке?", "topic":null}`. Для уточнения передать `topic` из ответа. Состояния ответа: `answered`, `clarify`, `unknown`. URL источника относителен к корню ассистента. Для нескольких распознанных частей вопроса массив `parts` содержит ответ на каждую часть, а верхний уровень сохраняет обычный формат ответа.

## Материалы и запуск для стажёров

В проверенной базе пока два документа кейса. Правила сопоставляют наборы слов независимо от их порядка. В `patterns` пробел разделяет обязательные группы, `|` задаёт варианты внутри группы, `*` отмечает основу слова. Проверка сценариев: `.venv/bin/python -m pytest -q tests intern_assistant/tests`. Ответы проверяются при редактировании базы и показываются вместе с источником. Примеры сообщений отделены от фактов. Чат не использует данные HR-дашборда и не хранит переписку на сервере. На сайте с реальными материалами разместить его за существующей авторизацией и публиковать там только документы, доступные стажёрам.

Для пилота стоит начать с вопросов, которые сейчас уходят HR и наставникам: первый день, доступы, контакты, ссылка и срок опроса. У каждой темы нужен владелец и дата проверки. Польза измеряется долей вопросов, после которых стажёр смог сам сделать следующий шаг, и списком повторяющихся вопросов без ответа. Для сбора вопросов в пилоте сначала согласовать правила хранения с HR.

Кабинет «Куб» на статическом Vercel использует общую базу через `web/shared/intern-assistant.js`. Запросы обрабатываются в браузере. Существующая памятка и действия обращения к HR остаются доступны. Публикуй в JSON только разрешённые выдержки из документов.
