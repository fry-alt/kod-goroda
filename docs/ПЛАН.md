## Как я вижу решение (одна картинка)
```
Google Forms ×2 ──► Google Sheets ──► бэк: опрос CSV раз в 5 с ──► история ──► анализ ──► /api/* ──► дашборд
(стажёр, наставник)  (ответы)            (+ вебхук Apps Script)     (xlsx кейса   оценки:     JSON по     (web/, опрос
                                                                     + новые)     правила;    контракту   /api/version
                                                                                  тексты:                 раз в 3 с)
                                                                                  YandexGPT
                                                                                  → офлайн)
```
**Почему так:**
- **Опрос опубликованного CSV** из таблицы ответов работает без туннеля и белого IP, Wi-Fi МТУСИ ему не помешает.
  Это «интеграция через API» из кейса. Вебхук (Apps Script `onFormSubmit` → `POST /api/webhook/{form}`) — второй
  канал, если поднимется туннель (cloudflared / ngrok). Запасной вариант на защите — скрипт, который шлёт тот же JSON.
- **Оценки считают правила**, у каждого вывода есть основание: личная норма, падение, разрыв стажёр ↔ наставник,
  пропуск опроса. **Тексты размечает ИИ**: тема, тон, риск, цитата, плюс резюме и действия для HR. Работает через
  уже готовый слой Андрея `feedback/analyzers/llm.py` (YandexGPT → Claude → офлайн). Результат кешируется по хешу
  текста, поэтому демо быстрое и не зависит от сети.
- **Фронт** — отдельная страница `web/` (HTML + JS + Chart.js), её раздаёт FastAPI. Она опрашивает `/api/version` и
  перерисовывается сама — так на защите видно «дашборд обновился». `app/dashboard.py` (Streamlit) не развиваем,
  оставляем как запасной.

**Что в данных:** на Месяц 6 почти все «зелёные», проблемы были раньше. СТ-003 — провал в мес. 2–3, СТ-004 —
перегрузка в мес. 4, СТ-005 — разрыв понятности задач в мес. 1–3. Поэтому в дашборде есть **переключатель
«на Месяц N»**: на нём видно, что система поймала бы все три случая вовремя. Это наша метрика проверки для
слайда: «3 из 3 известных эпизодов, поймано в том же месяце».
