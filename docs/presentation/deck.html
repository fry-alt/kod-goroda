Как мы поняли задачу
HR узнаёт о проблеме, когда стажёр уже ушёл

Мало данных

5 пар «стажёр — наставник», 6 опросов. Обучать модель не на чем: нужны прозрачные правила.

Разные взгляды

Стажёр оценивает свой опыт, наставник — его работу. Ценность в расхождении этих оценок.

Главное в тексте

«Нагрузка слишком высокая» звучит в комментарии раньше, чем падает средний балл.

Наша цель: каждый новый ответ из формы за секунды попадает в историю стажёра. HR получает сигнал с основаниями (какие оценки, какая цитата) и готовое действие.

Комментарии → ИИ

YandexGPT размечает тему, тон, риск и находит цитату-основание. Без сети работает офлайн-словарь, поэтому демо не зависит от интернета.

Архитектура и ИИ-технологии
работает и в закрытом контуре

Интеграция

Google Forms → Google Sheets → API (опрос раз в 5 с) и вебхук Apps Script → FastAPI. Можно заменить на Яндекс Формы: меняется только адаптер.

Анализ

Python, pandas: личная норма, динамика, разрывы пар, пропуски. Каждый вывод хранит свои основания.

ИИ

YandexGPT 5.1 (Yandex AI Studio): тема, тон, риск, цитата, резюме, действия для HR. Запасной вариант — офлайн-правила без внешней модели.

Данные о людях

Только ID (СТ-00X, Н-00X), без ФИО. В модель уходит текст комментария без персональных данных. Решение о человеке принимает HR: система лишь подсвечивает.

Инструменты разработки

Claude Code — ассистент при написании кода и документации. Весь код в репозитории, тесты — pytest.
