# Презентация (Артём)
- `deck.html` — слайды 1920×1080 по брендбуку МГТС (шрифты MTS, палитра, фоны из брендбука). Правим текст здесь.
- `./render.sh` → `out/slide-N.png` + `out/deck.pdf`; `./render.sh final` — без оранжевого пунктира «доделать».
- `node build_pptx.js` → `out/Радар_стажировки_МГТС.pptx` (слайды-картинки + **видео demo.mp4 на слайде 4** + заметки докладчика).
  Нужен pptxgenjs: `npm i --no-save pptxgenjs` в этой папке.

## Что доделать (пунктир на слайдах)
1. `demo.mp4` — скринкаст 30–40 с (Cmd+Shift+5 → запись области 1920×1080, без звука, ускорить ожидание),
   `shots/demo_poster.png` — первый кадр.
2. `shots/overview.png`, `shots/card.png` — скриншоты дашборда (обзор и карточка).
3. Слайд 6 — сверить с `tests/test_case.py`. Слайд 9 — ссылки на прототип и формы.
4. Сдача: `out/deck.pdf` **и** `.pptx` (видео играет только в PPTX; в PDF — постер).
