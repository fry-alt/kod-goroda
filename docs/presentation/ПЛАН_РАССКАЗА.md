## Три главные мысли (если забыл всё остальное)
1. Анкеты **приходят сами** — HR ничего не выгружает.
2. Сигнал **с основаниями** — видно, на каких оценках и цитатах он построен.
3. Есть **что сделать** — встреча, обратная связь, Huntflow, отчёт в один клик.

## Вопросы, которые могут задать
- **«Где тут ИИ?»** — YandexGPT разбирает комментарии (тема, тон, риск, цитата), пишет резюме и отвечает в чатах. Оценки считают прозрачные правила: данных мало (5 стажёров × 6 месяцев), обучать модель не на чем.
- **«А если ИИ ошибётся?»** — у каждого сигнала видны основания, HR может отметить «ложная тревога». Решение о человеке всегда за HR.
- **«Без интернета работает?»** — да, офлайн-правила; демо не зависит от сети.
- **«Персональные данные?»** — только ID (СТ-00X, Н-00X), без ФИО.
- **«Как внедрить?»** — формы можно заменить на Яндекс Формы, меняется только адаптер; сервер уже работает, деплой автоматический.
