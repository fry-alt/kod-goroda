# Данные, формы, интеграция, API (Андрей, issue #1)

## Запуск
```bash
source .venv/bin/activate
uvicorn api.main:app --port 8000          # при старте сам загрузит xlsx кейса в data/app.db
```
- Дашборд Артёма: `http://localhost:8000/` (раздаётся из `web/`).
- Swagger: `http://localhost:8000/docs`, состояние: `/health`.
- После репетиции стереть тестовые ответы: `python -m feedback.store --reset`, затем **перезапустить API**.
  Сброс запоминает время: строки Google Таблицы с более ранней «Отметкой времени» опрос больше не применяет,
  поэтому ответы с репетиции не вернутся и не перезапишут историю кейса.

## Как ответ попадает в систему
```
Google Form   ──onFormSubmit (Apps Script)──► POST /api/webhook/{intern|mentor}?source=google ─┐
     └──► Google Sheet ──CSV раз в 5 с (api/poller.py) ───────────────────────────────────────┤
Яндекс Форма  ──интеграция «HTTP-запрос»─────► POST /api/webhook/{intern|mentor}?source=yandex ─┤
tools/send_test_answer.py (запасной) ────────► POST /api/webhook/{intern|mentor}?source=test ───┤
                                                                                                 ▼
                       ingest.flatten_answers → parse_form_answer → store.upsert → version+1 → фронт (/api/version раз в 3 с)
```
- **Все каналы — один разбор.** Google работает даже без туннеля: CSV читаем сами.
- **Привязка.** `ID стажера` + `Контрольный период` («Месяц 7» → 7). Повторный ответ за тот же месяц
  заменяет старый. Одинаковые строки версию не меняют.
- **Подстановка.** Подразделение и ID наставника берём из истории, если форма их не прислала.
- **Валидация.** Оценки 1–5 обязательны, иначе 422.
- **Заголовки вопросов** в форме — «<столбец xlsx> — <вопрос>». Бэк узнаёт столбец по началу заголовка.

## Формы (5 минут)
1. `https://script.google.com` → новый проект → вставить [tools/google_forms.gs](../tools/google_forms.gs).
2. Вписать `WEBHOOK_URL` (адрес туннеля) и `WEBHOOK_SECRET` (как в `.env`). Без туннеля оставить пустым.
3. Запустить `createForms` и разрешить доступ.
4. Из журнала выполнения взять ссылки на формы и строки `SHEET_CSV_INTERN=` / `SHEET_CSV_MENTOR=`.
   Строки положить в `.env`, затем перезапустить API.

Туннель (если сеть пускает):
- `cloudflared tunnel --url http://localhost:8000`
- или `ngrok http 8000`

Новый адрес → вписать в скрипт и запустить `setWebhook`.

## Яндекс Формы (второй внешний сервис, только через вебхук)
Программно Яндекс Формы не создаются, их делаем руками в https://forms.yandex.ru (≈10 минут на обе).
Нужен **публичный адрес** API: у Яндекса нет таблицы, которую мы могли бы опрашивать без ключей.

**1. Туннель.**
- `npx localtunnel --port 8000` (node у нас есть);
- или `cloudflared tunnel --url http://localhost:8000`;
- или tuna.am / cloudpub.

Проверка: открыть `<адрес>/health` с телефона.

**2. Две формы.** Заголовки вопросов — как в таблице ниже: **название столбца в начале**, после него « — » и
текст вопроса. Только так бэк понимает, какой это показатель.

| Поле | Тип в Яндекс Формах | Варианты |
|---|---|---|
| `ID стажера` (и `ID наставника` в форме наставника) | Выпадающий список, обязательный | СТ-001…СТ-006 / Н-001…Н-006 |
| `Подразделение / направление стажировки` | Выпадающий список | Технический блок, Коммерческий блок, Административный блок, HR-блок, IT |
| `Контрольный период` | Выпадающий список, обязательный | Месяц 1 … Месяц 7 |
| 7 оценок стажёра / 6 оценок наставника | Шкала 1–5 (или «Оценка»), обязательная | заголовок «<столбец> — <вопрос>», тексты — в [tools/google_forms.gs](../tools/google_forms.gs) |
| 2 открытых вопроса | Длинный текст | «Сложности за период — …», «Что мешает работать и развиваться — …» / «Комментарий о работе за период — …», «Сложности / ситуации для внимания — …» |

**3. Интеграция.** В форме: Интеграции → HTTP-запрос (POST) или JSON-RPC POST.
- URL стажёра: `https://<туннель>/api/webhook/intern?source=yandex&secret=<WEBHOOK_SECRET>`.
- URL наставника: `https://<туннель>/api/webhook/mentor?source=yandex&secret=<WEBHOOK_SECRET>`.
- Тело: «все ответы» / JSON. Бэк понимает несколько форматов: объект ответа Яндекса
  (`answer.data.*.question.label`), JSON-RPC `params`, плоский `{вопрос: ответ}` и form-urlencoded.

Точные названия пунктов меню у Яндекса могут отличаться — **проверить на месте одной тестовой отправкой**.

**4. Если ответ не принялся.** Вебхук вернёт 422 со списком распознанных полей. Сырое тело запроса лежит в
`data/webhook_log.jsonl`. По нему видно, как Яндекс назвал поля, и разбор быстро допиливается в
`feedback/ingest.py::flatten_answers`.

В `last_event.via` видно, откуда пришёл ответ: `google` / `yandex` / `test`. На демо можно показать оба сервиса.

## Для Савелия: формат истории
`store.load_history(period=None) -> History(interns: DataFrame, mentors: DataFrame)`
- колонки — ровно как в xlsx кейса, плюс `period: int`, `source`, `received_at`;
- `period=N` — только строки с `period <= N`;
- `store.roster(hist)` — пары стажёр ↔ наставник и подразделение;
- списки колонок: `store.INTERN_SCORES`, `MENTOR_SCORES`, `INTERN_TEXTS`, `MENTOR_TEXTS`.

API вызывает `feedback.case.build_overview(hist, period)` и `build_intern(hist, intern_id, period)`.
Пока модуля нет, отдаёт данные в форме контракта без сигналов (`"analysis": "fallback"`).
