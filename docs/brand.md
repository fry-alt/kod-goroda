# Брендбук МГТС — главное для дашборда и презентации
Источник: https://disk.yandex.ru/d/uXw7Qs1IOmeFAg (zip 300 МБ, внутри `index.html`). Готовое подключение: `web/brand/brand.css`.

- **Цвета:** фон белый `#FFFFFF` · синий `#008AE0` (заголовки, акцент) · тёмно-синий `#134074` (текст) ·
  оранжевый `#FF7654` (ровно одна выделенная деталь). Голубой `#57A5D7` — только для знака.
  «Начинайте со светлого фона».
- **Шрифты:** заголовки MTS Extended Black. Лёгкая строка заголовка MTS UltraExtended Light. Крупные числа
  MTS Extended Medium. Текст MTS Text. OTF лежат в `web/brand/fonts/`.
- **Логотип:** `web/brand/logos/logo1..5.svg|png`. На светлом фоне — голубой или графитовый, на тёмном — белый.
  Не растягивать, не перекрашивать, без теней.
- **Графики:** динамика — линия, сравнение — столбцы. Выделяем одно главное значение, подписи и легенду оставляем.
  В таблицах числа выравниваем вправо и указываем период.
- **Презентация:** официальный шаблон `mgts-template-2026.pptx` (16:9). Обложка и перебивки — 3D-фоны со спокойной
  зоной под текст, на содержательных слайдах — один 3D-объект или иконка на тезис.
