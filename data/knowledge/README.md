# Документы компании для чата «Спросить Радар»

Кладите сюда `.md` / `.txt` (регламент стажировки, памятка наставнику, FAQ HR и т. п.).
Чат ищет по ним фрагменты под вопрос и отвечает с указанием документа.
Если в `feedback/knowledge.py` есть `search(question, k)` (умный поиск Савелия), используется он.
