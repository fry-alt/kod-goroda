## Что сделать (≈45 минут)

### 1. Бэк: `api/call.py` (новый файл, согласовано с Андреем)
WebSocket `/ws/call/{room}`. `room` — ID стажёра, например `СТ-002`. Хранение только в памяти, в базу ничего не пишем.
Сервер ничего не решает: он только пересылает сообщения между участниками комнаты.

Протокол — **ровно тот, что ждёт `room.js`** (смотри `handle()` в `source/room.js`):
| Клиент → сервер | Сервер делает |
|---|---|
| `{"type":"join","groupId":…,"mic":true,"cam":true}` | Себе: `{"type":"joined","you":ID,"peers":[{"id","mic","cam"}],"chat":[история],"question":null}`. Остальным: `{"type":"peer-joined","id":ID,"mic","cam"}` |
| `{"type":"signal","to":ID,"data":{…}}` | Адресату: `{"type":"signal","from":ID,"data":…}` (SDP и ICE, содержимое не трогаем) |
| `{"type":"state","mic","cam"}` | Остальным: `{"type":"state","id":ID,"mic","cam"}` |
| `{"type":"chat","text":"…"}` | Всем, включая автора: `{"type":"chat","id":N,"from":ID,"text":"…","at":ms}`. Текст обрезать до 500 символов (см. `cleanChat`), не чаще 8 сообщений за 10 с |
| `{"type":"leave"}` или разрыв | Остальным: `{"type":"peer-left","id":ID}`. Комната опустела — чат удалить |

ID участника — случайная строка, которую сервер выдаёт при подключении. Имя («HR», «Стажёр СТ-002») передаём
в `?name=` в адресе WS и отдаём в `joined.peers` и `peer-joined` полем `name`. Больше 3 человек в комнату не пускать
(`{"type":"error","message":"Комната заполнена"}`).

Скелет, от которого можно идти:

from collections import defaultdict
from fastapi import APIRouter, WebSocket, WebSocketDisconnect
import secrets, time

router = APIRouter()
rooms: dict[str, dict[str, dict]] = defaultdict(dict)   # room → id → {"ws", "mic", "cam", "name"}
chats: dict[str, list[dict]] = defaultdict(list)

async def _send(ws, obj):
    try: await ws.send_json(obj)
    except Exception: pass

async def _broadcast(room, obj, skip=None):
    for pid, p in list(rooms[room].items()):
        if pid != skip: await _send(p["ws"], obj)

@router.websocket("/ws/call/{room}")
async def call(ws: WebSocket, room: str, name: str = "Участник"):
    await ws.accept()
    me = secrets.token_hex(4)
    try:
        while True:
            msg = await ws.receive_json()
            t = msg.get("type")
            if t == "join":
                ...  # лимит 3, rooms[room][me] = {...}, joined себе, peer-joined остальным
            elif t == "signal":
                ...  # переслать rooms[room][msg["to"]]
            # state, chat, leave — по таблице выше
    except WebSocketDisconnect:
        pass
    finally:
        ...  # убрать из комнаты, peer-left остальным, пустую комнату и её чат удалить

@router.get("/api/call/ice")
def ice():

## Ограничения (сказать на защите честно, если спросят)
- Без TURN звонок между разными сетями может не соединиться (строгий NAT). Для демо оба участника — на одном ноутбуке
  или в одной Wi-Fi. Для боевого контура — TURN (coturn) или корпоративный ВКС, `ice-servers.js` уже это поддерживает.
- Камера в браузере работает только на `localhost` или HTTPS. На Vercel звонка не будет: там нет бэка.
- В скринкаст звонок не вставлять, если он не стабилен; хватит 5 секунд «нажал → открылась комната».
